PROJECT INFO - AC6: Raven WebGL Renderer
================================================================================

PURPOSE
  Single-file, offline-capable WebGL 3D renderer of Raven from Armored Core VI:
  Fires of Rubicon, built with HTML5, WebGL, Three.js, and vanilla JavaScript.

RUNTIME FILES
  index.html
    The only HTML and JavaScript source file. It contains the Three.js r128
    library, the matching GLTFLoader r128, all application logic, CSS, and UI.

  raven.glb
    The Raven 3D model loaded by index.html.

DOCUMENTATION
  README.md
    Project overview, controls, model instructions, and technical details.

  PROJECT_INFO.txt
    This file.

  LICENSE
    MIT License information.

HOW TO RUN
  1. Keep index.html and raven.glb in the same folder.
  2. Double-click index.html to open it in a modern browser.
  3. When opened directly from file://, click "Choose raven.glb" and select
     raven.glb from the same folder.
  4. The model is read locally from the user-selected File object and parsed
     by the embedded Three.js r128 GLTFLoader.

  No local server, build step, package manager, or internet connection is
  required. Browsers do not allow a file:// page to read adjacent files by
  pathname, so the explicit file selection is required.

  When hosted on HTTP(S), raven.glb is loaded automatically from the same
  folder as index.html.

FEATURES
  - Raven GLB model loaded with the embedded Three.js r128 GLTFLoader.
  - Local GLB file selection for direct file:// use.
  - Automatic adjacent GLB loading when hosted over HTTP(S).
  - Procedural placeholder mech used if the model cannot be loaded.
  - Industrial maintenance hangar with concrete floor, corrugated walls, roof trusses, service benches, tool cabinets, task lights, and floating dust.
  - NIGHTFALL suspended beneath a workshop gantry crane by a four-point sling.
  - Nine clickable inspection systems with technical records and Armored Core VI game intel.
  - Component selection through both 3D hotspots and the component index.
  - Optional low-frequency suspension sway with a hold-position control.
  - Collapsible dossier panel and fullscreen inspection mode.
  - Orbit controls: left-drag to rotate, middle-mouse drag to pan within limits, wheel to zoom.
  - Touch support with one-finger rotation.
  - On-screen author watermark.

MODEL CONFIGURATION
  The model path is configured near the top of the inline application code in
  index.html:

    modelPath: './raven.glb',

  Set modelPath to null to display the procedural placeholder instead.

  The GLTFLoader implementation is embedded in index.html and matches Three.js
  r128. No separate loader file is required.

CONTROLS
  - Play / Pause / Restart: control the dash animation.
  - Time of Day: adjust sunlight and scene lighting.
  - Load Raven Model: select a local GLB file.
  - Recenter View: restore the initial camera position and framing.
  - Collapse / Expand: hide or show the sidebar.
  - Fullscreen: use the sidebar button or floating top-right button.
  - Rotate: left mouse drag or one-finger touch drag.
  - Pan: hold the middle mouse button and drag. Movement is clamped to keep the model in view.
  - Zoom: mouse wheel.

ANIMATION
  - The dash cycle repeats every CONFIG.dashDuration seconds (default: 1.6).
  - The mech leans forward in proportion to CONFIG.leanAngle.
  - Recognized nozzle effects scale and change opacity with dash intensity.
  - Unrecognized thruster locations are not guessed, preventing detached flames.
  - A subtle hover bob is applied during the animation.

LIGHTING
  - Procedural cube-map reflections for metallic GLB materials.
  - Fixed studio key, fill, and rim lights keep the model readable at night.
  - Adjustable directional sunlight, atmospheric sky gradient, ambient fill,
    and fog adapt to the selected time of day.
