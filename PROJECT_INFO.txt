PROJECT INFO - AC6: Raven WebGL Renderer
================================================================================

PURPOSE
  Single-file, offline-capable WebGL 3D renderer of Raven from Armored Core VI:
  Fires of Rubicon, built with HTML5, WebGL, Three.js, and vanilla JavaScript.

RUNTIME FILES
  index.html
    The only HTML and JavaScript source file. It contains the Three.js r128
    library, the matching GLTFLoader r128, all application logic, CSS, and UI.

  raven.glb
    The Raven 3D model loaded by index.html.

DOCUMENTATION
  README.md
    Project overview, controls, model instructions, and technical details.

  PROJECT_INFO.txt
    This file.

  LICENSE
    MIT License information.

HOW TO RUN
  1. Keep index.html and raven.glb in the same folder.
  2. Start a local static web server in this folder (for example, VS Code Live
     Server).
  3. Open the served index.html in a modern browser.

  No build step, package manager, external JavaScript file, or internet
  connection is required. A local server is recommended because browsers can
  block GLB loading from file:// URLs.

FEATURES
  - Raven GLB model loaded with the embedded Three.js r128 GLTFLoader.
  - Procedural placeholder mech used if the model cannot be loaded.
  - Dash animation with forward lean and animated thruster flames.
  - Play, pause, and restart controls.
  - Collapsible sidebar and fullscreen mode.
  - Adjustable time-of-day lighting from 0 to 24 hours.
  - Orbit controls: left-drag to rotate, right-drag to pan, wheel to zoom.
  - Touch support with one-finger rotation.
  - Gradient sky, dark ground plane, and subtle grid.
  - On-screen author watermark.

MODEL CONFIGURATION
  The model path is configured near the top of the inline application code in
  index.html:

    modelPath: './raven.glb',

  Set modelPath to null to display the procedural placeholder instead.

  The GLTFLoader implementation is embedded in index.html and matches Three.js
  r128. No separate loader file is required.

CONTROLS
  - Play / Pause / Restart: control the dash animation.
  - Time of Day: adjust sunlight and scene lighting.
  - Collapse / Expand: hide or show the sidebar.
  - Fullscreen: use the sidebar button or floating top-right button.
  - Rotate: left mouse drag or one-finger touch drag.
  - Pan: right mouse drag.
  - Zoom: mouse wheel.

ANIMATION
  - The dash cycle repeats every CONFIG.dashDuration seconds (default: 1.6).
  - The mech leans forward in proportion to CONFIG.leanAngle.
  - Thruster flames scale and change opacity with dash intensity.
  - A subtle hover bob is applied during the animation.

LIGHTING
  - Directional sunlight with shadows.
  - Hemisphere and ambient lighting.
  - Sun color, intensity, sky gradient, ground color, and fog adapt to the
    selected time of day.
